# Power Query – Data Cleaning Project

**Portfolio Project | Data Analytics**

## 📌 Project Overview

This project demonstrates my data cleaning and transformation skills using Microsoft Power Query.

The goal is to transform raw, inconsistent business data into a clean, structured dataset suitable for data modeling and reporting.

## 🧹 Data Cleaning & Transformation Operations

- Removing duplicate records
- Identifying and handling missing values
- Correcting and standardizing data types
- Standardizing text values and formats
- Splitting and merging columns
- Identifying and handling errors
- Transforming and formatting date values

## 🛠️ Tools & Technologies

- Microsoft Excel
- Power Query
- Power Query M Language

## 🎯 Project Objective

To demonstrate the ability to prepare raw business data for further analysis by applying systematic data cleaning, transformation, and validation techniques.

## 📊 Expected Outcome

A clean, consistent, and structured dataset that can be used for further data modeling, business intelligence, and reporting.
